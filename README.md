
# To-Do List Web App

This is a simple To-Do List application built with HTML, CSS, and JavaScript. It allows users to add tasks, mark them as completed, and remove them from the list. The tasks are saved in the browser's `localStorage`, so even after refreshing the page, the tasks remain.

---

## Features

- **Add Tasks**: Enter a task in the input field and click "Add" to add it to the list.
- **Mark as Completed**: Click on a task to toggle its completion status. Completed tasks are crossed out.
- **Remove Tasks**: Click the "×" button next to a task to remove it from the list.
- **Persistence**: Tasks are saved in the browser's `localStorage`, ensuring they persist after page reloads.

---

## Tech Stack

- **HTML**: The structure of the web page.
- **CSS**: The styling of the web page to make it visually appealing.
- **JavaScript**: The logic behind adding, completing, and removing tasks, as well as saving and loading tasks from `localStorage`.
